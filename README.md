# Semestrální práce – Databázový projekt

## Popis
Databáze pro jednoduchou To‑Do aplikaci. Obsahuje dvě tabulky: `users` a `tasks`.  
Součástí jsou ukázky SQL DDL a SQL DML dotazů.

## Struktura databáze
- `users(id, name)`
- `tasks(id, user_id, title, completed, created_at)`

## Použité SQL
- DDL: CREATE, ALTER, DROP (ukázka)
- DML: INSERT, UPDATE, DELETE, SELECT
- SELECT: WHERE, JOIN, ORDER BY, GROUP BY, agregační funkce, poddotaz

## Spuštění
Dotazy lze spustit v MySQL / MariaDB (případně jiném SQL systému s drobnými úpravami).
